# Release notes

Major releases from the last two years, newest first.

## Release 6.2 (October 2026)

- **B2B wholesale price lists** on Scale and Enterprise: create customer groups with their own prices, minimum order quantities and payment terms (Net 15 / Net 30).
- **SAR payouts**: Saudi stores can now receive NestPay payouts in Saudi riyal.
- **Faster checkout**: checkout page weight cut by 35%; median load time on 4G is now 1.1 seconds.
- **Order editing**: add or remove items on unfulfilled orders, with automatic payment adjustment.

## Release 6.1 (July 2026)

- **AI product descriptions** in English, Urdu and Arabic, from the product editor.
- **Urdu storefronts**: full right-to-left support in all free themes, with Nastaliq font options.
- **Bundles** now support up to 10 components (previously 5).
- **Bulk editor** for prices and inventory across up to 5,000 variants at once.

## Release 6.0 (March 2026)

- **API v2 generally available**, with cursor pagination, idempotency keys and scoped API keys.
- **API v1 deprecated**; it will be switched off on 31 March 2027. A migration guide is in the developer docs.
- **Webhook signatures** now include a timestamp header (`X-Nestora-Timestamp`) to prevent replay attacks.
- New official **Node.js SDK** (`@nestora/node`); the PHP SDK reached version 3.0.

## Release 5.4 (November 2025)

- **Multiple inventory locations**: up to 2 on Growth and 10 on Scale.
- **Nestora POS 2.0** with offline mode and receipt printing over Bluetooth.
- **Abandoned-cart recovery over WhatsApp** in addition to email.

## Release 5.2 (June 2025)

- **Mandatory two-factor authentication** for store owners.
- **COD verification over WhatsApp**, with SMS fallback; unconfirmed orders auto-cancel after 48 hours.
- **COD risk rules** to block cash on delivery for customers with repeated refused parcels.

## Release 5.0 (January 2025)

- **New one-page checkout**, which raised average conversion by 11% in testing.
- **Theme Store** launched with premium themes from independent designers.
- **Saudi Arabia** support: Mada cards, Arabic storefronts and BlueCamel Logistics deliveries.

## What's next

The public roadmap at https://www.nestora.example/roadmap lists planned features. Items currently in development include subscriptions (recurring orders), a loyalty programme and a native mobile app for merchants on iOS. Nestora does not commit to release dates for roadmap items.
